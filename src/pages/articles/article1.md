This will serve as an example news article, which can be written as a markdonwn file.

## What I've Learned
- `.astro` files are for things like pages and components (they're reusable!)
- using tailwind is quite simple
- it seems you need the whole `<html>` bit on every page
- lots of this stuff is static HTML
- the stuff in the `---` is called **frontmatter**. This is info about the post that Astro can use in other stuff. It doesn't show up in the page but can be accessed elsewhere.
- don't ever include `.md` or any file extensions... interesting.
